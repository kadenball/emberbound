# Local validation — 0.8.0, 2026-09-08

- **100 simulation tests passed**, including full twelve-chapter campaigns for each of three heroes with each of three fighting styles, earned progression, capped defeat payouts and at most three attempts per chapter. New checks cover story-save migration and machine timing, jump/overhead differences, safe lanes, enemy damage, shutdown switches and syrup movement.
- **55 browser checks passed**, with eight inapplicable combinations skipped, across desktop Chromium, Android-sized Chromium and iPhone-sized WebKit. Includes story advance/skip/replay/persistence, menu-track playback following a real gesture, Music controls, gameplay-track playback and menu resume.
- All twelve distinct chapter MP3s decode to stereo audio longer than 30 seconds in the browser. All chapter files match their manifest SHA256 and decode end to end in ffmpeg. The supplied menu recording also decodes fully and retains its documented hash.
- Strict TypeScript, production Vite build and Capacitor Android/iOS sync passed. A redundant unreachable color comparison detected by TypeScript was removed after the browser run; no reachable rendering behavior changed.
- Android `assembleDebug bundleRelease lintRelease` passed, version 0.8.0/code 8. The debug APK is installable; the release AAB remains unsigned. Existing dependency lint baseline retained. `scripts/package.py` checks every bundled web/audio byte against the current production build before writing the download artifacts.
- Xcode project syntax and iOS plists parse. Native iOS compilation/signing cannot be verified on this Linux host.
- Normal desktop/mobile game captures and six regional renderer fixtures recorded no page errors. Woodland, laundry, candy and junkyard fixture images plus the mobile game image were visually inspected. Fixtures place actors directly for art review and do not establish gameplay success.
- Static district art uses the existing bounded terrain-chunk cache. This is an implementation safeguard, not a measurement of physical-device performance.

The browser and simulation suites verify behavior; they do not establish human enjoyment, musical quality or parity with Castle Crashers/Super Meat Boy. Direct human playtests, listening review, mid-chapter retry design, native iOS builds, physical-device performance and real-device interruption handling remain outstanding.
