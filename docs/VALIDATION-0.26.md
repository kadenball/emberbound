# Local validation — 0.26.0, 2026-09-08

- **209 simulation tests passed** across 23 files, including all nine earned-progression hero/style campaigns. Five new cart checks exercise real Light/Heavy input, directional rejection, momentum, one hit per enemy, braced-brute blocking, the axle cooldown, destination clamping and one-time rewards. A strengthened arrival assertion caught the remaining boost value after completion; the final suite passes with boost/cooldown cleared. The subsequent completed-delivery objective change is text only.
- **18 regional cargo browser checks passed**: six journeys × desktop Chromium, Android-sized Chromium and iPhone-sized WebKit. A driver reaches each delivery with normal inputs, positions the hero through steering, pauses for capture, then releases on an actual Heavy input (desktop keyboard, phone-sized touch). It asserts over 100 world units of rush movement and the live objective. No enemy, wave, HP or position edits are used. The first run passed 15 and failed three Android captures because the driver released time before sending the touch; releasing on the actual input resolved all 18. Browser captures precede the arrival-settling flags/text correction; that change is covered by simulation and build checks, not a new end-of-delivery browser capture.
- Six regional phone captures were inspected. The soup/ladle, soft-serve coffin, sock hamper, toothed cake, fork crate and crowned mail have distinct silhouettes. Motion follows cargo state and wheel distance. These captures demonstrate rendering and input plumbing; they do not establish human recognition, touch comfort, sustained co-op or enjoyment.
- The final **432-run matched combat audit** reuses 0.25's profiles, seeds and policies with no changed win/loss outcomes: Light **0/108**, Heavy **25/108** (bosses **13/54**), Light + power **22/108** (bosses **15/54**), mixed **103/108** (bosses **51/54**). All terminate. Its policies were not updated to optimize cart use; the new mechanic's best strategy and broader exploits remain unproven. An unintended change to ordinary escort blocking was reverted before this final audit. [Raw evidence](COMBAT-AUDIT-0.26.json).
- Strict TypeScript, Vite production build and Android/iOS Capacitor sync passed. The first type check caught a drawing-helper annotation that omitted CanvasPattern; the annotation now matches the existing shape helper. Final JavaScript **355.86 kB / 129.72 kB gzip**; CSS **54.32 kB / 12.38 kB gzip**.
- Android `assembleDebug bundleRelease lintRelease` passed with final assets. Manifest confirms **0.26.0 / code 26**. Packaging compares every current web/audio asset against both native packages and writes checksums. The debug APK is installable; the release AAB remains unsigned.
- Xcode project syntax and both iOS plists parse. Native iOS compilation, signing and physical-device behavior remain unverified on Linux. Native Android lifecycle/storage evidence is the **0.24 API 36 emulator smoke**, not a 0.26 native campaign run.
